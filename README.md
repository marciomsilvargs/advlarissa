# Dra. Larissa Daudt — Advocacia Previdenciária

Landing page institucional e informativa para atendimento jurídico especializado em Direito Previdenciário.

## Tecnologias

- HTML5 / CSS3 / JavaScript (Vanilla)
- Node.js (servidor local estático sem dependências externas)
- Google Fonts (Cormorant Garamond, Inter)

## Execução Local

Para rodar o projeto localmente em sua máquina:

```bash
# Iniciar o servidor local
npm start
# ou
node server.js
```

Abra no navegador em [http://localhost:3000](http://localhost:3000).
